قارئة الأنشطة المدرسية - نسخة GitHub Pages

ما الجديد:
- الشرح الصوتي لكل صفحة أصبح بصوت طالبة مصرية حقيقية (سلمى - ar-EG-SalmaNeural)
  بدل الاعتماد على صوت الجهاز.
- ملفات الصوت محفوظة في مجلد audio وتعمل دون اتصال بالإنترنت بعد أول فتح.
- تم إصلاح أخطاء التشغيل: تشغيل تلقائي مع تقليب الصفحات، منع التكرار،
  رسائل واضحة عند حجب تشغيل الصوت، وصوت احتياطي من الجهاز لو تعذّر تشغيل الملفات.

الرفع على GitHub:
ارفع محتويات هذا المجلد إلى جذر المستودع، ثم Settings > Pages >
Deploy from a branch > main > /(root) > Save.
افتح الرابط مرة مع الإنترنت حتى تُحفظ الصفحات وملفات الصوت للاستخدام دون اتصال.

إعادة توليد الصوت (اختياري):
ملفات الصوت مرفقة جاهزة، ولو حبيت تعدّل النصوص أو تُعيد توليدها:
1) ثبّت بايثون.
2) نفّذ: pip install edge-tts
3) نفّذ من داخل مجلد المشروع: python tools/make_audio.py
النصوص تُقرأ تلقائيًا من مصفوفة pages داخل index.html حتى يتطابق الصوت مع الشرح المكتوب.

ملاحظات:
- التشغيل التلقائي للصوت يحتاج ضغطة واحدة على «اسمعي الشرح» أول مرة (سياسة المتصفحات).
- الصوت الاحتياطي يعتمد على الأصوات المثبّتة على جهاز المستخدم.
